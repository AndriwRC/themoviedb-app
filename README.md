# TheMovieDB App - Single Page Application (SPA)

## Overview

**TheMovieDB App** is a Single Page Application (SPA) built using **Vanilla JavaScript**. The primary goal of the project is to practice making asynchronous requests to the [TheMovieDB API](https://developer.themoviedb.org/reference/intro/getting-started). The application allows users to browse and search for movies, displaying relevant data fetched from the API. The design was adapted from the base repository provided by Platzi.

## Features

- **Asynchronous API requests**: Uses the Fetch API to retrieve movie data.
- **Dynamic content**: Movie details are rendered dynamically based on API responses.
- **Search functionality**: Users can search for movies by name.
- **Single Page Application**: The app dynamically updates content without requiring a page reload.
- **Responsive Design**: Adapted to different screen sizes.


## Tech Stack

- **Vanilla JavaScript**: For making asynchronous requests and DOM manipulation.
- **Fetch API**: To interact with TheMovieDB API.
- **HTML5 & CSS3**: For structuring and styling the application.

## API Integration

The app uses the [TheMovieDB API](https://developers.themoviedb.org/3/getting-started/introduction) to fetch movie data. You need an API key from TheMovieDB to access the API.

## Design

The UI and design layout were adapted from the base project provided by [Platzi](https://github.com/platzi/curso-api-rest-javascript-practico/tree/d0f14b4597a65711eb449e3cd962b2811ed6135c). Styling was done with basic CSS to keep the project simple and focused on API interactions.
